# Code of Conduct

## Our commitment

We aim to make participation in this project respectful and constructive for everyone.

## Expected behavior

- Be considerate and respectful.
- Give actionable, evidence-based feedback.
- Accept constructive criticism.
- Focus on the work, not personal attacks.

## Unacceptable behavior

Harassment, discrimination, threats, deliberate disruption, or sharing private information without consent are not acceptable.

Project maintainers may edit or remove comments and contributions that violate these expectations.
